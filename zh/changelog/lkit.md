# lkit 版本变化

[lkit](https://github.com/landscape-router/landscape-kit) 是 Landscape 的配套运维工具: 一个用来安装和
运维 Landscape 实例的终端控制台加命令行, 覆盖首次部署、手工部署迁移、更新、版本切换、修复、备份、
网络接管和服务生命周期管理. 它还带一条 Terrain 防失联通道(flare): 常规 IP 路径不可用时,
用 `lflare` 客户端与路由器建立加密的二层应急管理连接. 这里只列它自己的版本变化,
其中和主项目的适配会重点标出. 主项目的版本变化见 [版本变化](./).

lkit 的版本号和主项目各走各的线, 不要混着看. 每个版本给一句摘要, 详细条目同样收在折叠区里.

版本标题上带 <Badge type="warning" text="预发布" /> 标注的, 是预发布版本. lkit 早期这些 tag 没有对应的
GitHub Release, 所以按版本号里的 `-rc.N` 判断; 有 Release 的以 GitHub 的 pre-release 标记为准.

页面只保留**近半年**发布的版本(2026-04-11 之后); lkit 目前全部版本都在范围内.

## 未发布

`lkit self update` 现在也可以用来升级 lkit 自己, 与 `lkit self upgrade` 等价. 改动已经在 main 上,
但截至 2026-10-11 还没有对应的发布版本.

## v0.6.2 (2026-10-09)

flare 遇到协议版本不一致时会明确报错, 并修掉握手包被重复捕获导致中断的问题.

::: details 详细变化

- flare 检测到协议版本不匹配时, 直接回一个明文错误帧明确失败, 不再静默卡住.
- 修复桥接双抓包拓扑: 同一个 DISCOVER 被捕获两次时, 握手仍然能完成.
- flare 的中继调优常量和 scrypt 指数参数统一到 landscape-terrain-proto, 由共享 crate 提供.
- 清理 service crate 里不再使用的重导出(re-export)和死代码.
  :::

## v0.6.1 (2026-10-06)

含预发布版 v0.6.1-rc.1、v0.6.1-rc.2 的变更(正式版只提了版本号)。小修: 回环流量不再被环境代理接管.

::: details 详细变化

- 回环流量保持直连, 不再走环境变量里的代理.
- 修正 mock 镜像刷新测试受路径覆盖(paths override)影响的问题.
  :::

## v0.6.0 (2026-10-01 → 2026-10-06)

含预发布版 v0.6.0-rc.2 的变更(正式版只提了版本号)。这一版的重点是安装流程适配新版主项目,
以及控制台交互成体系地打磨。
安装时改用 `landscape config` 生成 init 配置, 对应主项目 0.25.1 及以后的版本.

::: details 详细变化

- 安装时生成 init 配置的方式改为调用主项目的 `landscape config`, 适配 0.25.1 及以后.
- 适配主项目“由参数是否出现决定行为”的 config 子命令语义.
- 端口检查会结合安装状态判断: 被正在运行的 Landscape 占用的端口视为预期情况.
- 控制台改为键盘优先的导航, 对话框与列表布局统一, 按键提示集中到状态栏, 状态栏最多两行提示.
- 用快照把对话框、阻塞页面和整屏布局都固定下来, 并接入 docker 渲染的布局图集与真实 PTY 的面板走查.
- flare: F3 在任意上下文切换语言; 认证被明确拒绝后不再重试; 日志行数按物理行计算;
  TUI 的交互约定与控制台对齐.
- 内部整理: 控制台的后台任务改走按面板的 ops trait; 文档与测试脚手架更新.
  :::

## v0.5.0 (2026-08-30)

支持自定义前端资源来源, 备份和静态修复改为从实际运行的静态目录打包.

::: details 详细变化

- 前端资源支持用户自定义来源, 不再只能用内置的.
- 备份和静态修复改为从运行中的静态目录打包; 静态修复改成意图驱动.
- 修正静态修复遇到损坏配置时直接失败的问题.
- 测试: 前端自定义来源的场景纳入 fixture e2e; 读取归档时会跳过 `.lkb` 元数据头.
  :::

## v0.4.3 (2026-08-20)

恢复码对话框加宽, 避免长内容被截断.

## v0.4.2 (2026-08-20)

含 v0.4.1 的变更。自升级和 CI 的小修.

::: details 详细变化

- 自升级前先把二进制置为可执行, 避免检查阶段就失败.
- CI: fixture e2e 的二进制只构建一次, 并按域并行; 补上自升级的 fixture 场景.
  :::

## v0.4.0 (2026-08-19)

集中修 flare 中继的并发与半关闭问题, 并去掉安装时的硬性内存限制.

::: details 详细变化

- 去掉安装时的硬性内存限制.
- flare 中继: 连接突发不再被拒, 服务端监听改为池化, 中继读写解耦, 大流量不会再让服务端任务被饿死(starve).
- flare 中继: 半关闭时数据不丢, 主动关闭后正确传播 EOF, 关闭前先 flush, 并拒绝过期的中继消息.
- 测试: 覆盖并发连接的生命周期和持续 TCP 传输; CI 按场景并行并共享构建缓存.
  :::

## v0.3.2 (2026-08-19)

含 v0.3.1 的变更。flare 的两个小修.

::: details 详细变化

- Windows 上显示可读的网卡名称.
- 监听器不再每次轮询都重建, 只接受处于 pending 状态的连接.
  :::

## v0.3.0 (2026-08-18)

迁移流程改为两阶段并由 daemon 代为切换; flare 有了交互界面和中文.

::: details 详细变化

- 迁移改为两阶段: 先检查导出接口, 再交给 daemon 执行切换.
- 迁移时前台会一直保持, 直到取消引发的回滚完成.
- daemon 启动时会预先拉起物理网卡, 供 flare 使用.
- flare 新增交互式会话界面, 拆成模块并接入 i18n, 端口映射导航也做了改进.
  :::

## v0.2.0-rc.2 (2026-08-17) <Badge type="warning" text="预发布" />

lkit 开始能管自己的一版: 拆出 lkit 自己的 territory, 新增常驻 daemon 代执行操作,
并把安装、卸载、迁移的测试补成体系. flare(Terrain 防失联通道)也是在这一版并入 workspace 的.

::: warning 需要注意的变更
不再支持 CentOS 7 / Stream; 移除 “none” 部署模式, 必须使用发行版自带的 init 系统
(systemd / openrc / sysvinit); 卸载只清理 Landscape 部分, 保留 lkit 自身与 daemon.
:::

::: details 详细变化

- 新增常驻的 lkit daemon, 前台操作可以交给它执行; 被中断的事务也能恢复.
- 服务管理抽象化, 支持 systemd、openrc 和 sysvinit.
- 拆出 lkit 自己的 territory, 与 Landscape 的安装目录分离; 卸载不再动 lkit 自身和 daemon.
- 新增 `lkit self install/upgrade/remove`, 可以管理 lkit 自己.
- 迁移: 支持把手工部署的 Landscape 迁移进 lkit 管理.
- 新增常用软件安装, 支持 Docker; 软件面板可以管理 Landscape 的基础软件包.
- 镜像源: 探测可用性并新增腾讯、华为镜像; 切换或恢复后刷新包索引;
  兼容 Fedora 的两种镜像目录布局; 切换时注释掉 CD-ROM 源.
- Docker 的安装源也支持腾讯和华为.
- 支持 ifupdown 的网络接管(network takeover).
- 新增 lkit reinit, 可以重建网络配置, 重建前先做保护性备份.
- 控制台拆成按域的模块, 新增备份/恢复面板和更新面板, 支持取消软件安装,
  备份列表改为带表头且显示大小.
- 网络接管向导重做; 安装结果页可以直接确认接管.
- flare: 把 Terrain 的二层协议并入 workspace; flare 改为由 lkit daemon 常驻托管, 安装时下发恢复密钥(psk),
  也支持交互式补发.
- flare 协议演进: v2 加密会话与双向认证, v4 用 psk 派生的密钥封装(seal) DISCOVER/RESP 并防重放,
  v5 用 scrypt 拉伸主密钥、按方向派生握手密钥、认证帧绑定 MAC; 同时加固了针对 MAC 伪造的 DoS.
- flare: 实现基于用户态 smoltcp 协议栈的二层端口转发; 修掉 Windows 上的传输死锁.
- 安装时如果已存在有效的安装状态, 直接拒绝重复安装.
- 测试: 大量 e2e 与场景覆盖, 包括在 systemd-nspawn 里验证真实 daemon 委派.
  :::
