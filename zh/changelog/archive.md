# 历史版本

主项目 [Landscape Router](https://github.com/ThisSeanZhang/landscape) 在 2026-04-11 之前发布的版本.
近半年的版本见 [版本变化](./), 整理方式与标注规则和主页面一致.

## v0.17.5 (2026-03-25)

指标存储重构以加快启动; 指标模式与 DuckDB 恢复处理调整.

::: details 详细变化

- 邻居的 `neigh_update` kprobe 不存在时, 优雅处理而不是报错.
- 指标存储重构, 启动更快; 连接写入路径和存储后端重做, 全局统计默认走缓存.
- 指标模式重做, DuckDB 的恢复处理加固.
- 关机信号处理从 ctrlc 换成 tokio.
- 生成 id 和 `update_at` 的默认值对齐.
- 重构 eBPF handle 和错误上下文.
- 修正 DNS 里 IPv6 link-local 客户端按 MAC 派生地址解析的问题.
  :::

## v0.17.3 (2026-03-17)

网关反向代理上线; 证书支持 EC 私钥和通配符匹配; 新增回滚子命令与时间同步.

::: details 详细变化

- 新增带 SNI 的网关反向代理, 含配置、数据库和界面管理.
- 网关支持 HTTPS 终止和直通路由, 主机路由和编辑器布局也重新整理.
- 没有证书时网关可以先监听 443, 证书就绪前阻塞连接.
- 证书解析支持 EC 私钥; 新增生成式证书模式; 证书能自动回退重新生成;
  修正通配符域名的证书匹配.
- 接入常见的 ACME DNS 服务商; 网关和接口的证书域名会同步到动态 DNS.
- DNS 新增动态重定向, 本地重定向的应答改用路由快照; 修掉特定场景下的 DNS 死锁.
- 新增数据库回滚子命令.
- 新增时间同步服务.
- 新增指标的总体开关.
- 新增调用方身份的查询接口.
- 之前关闭当前正在使用的接口会直接断网, 现在会先弹确认.
- NAT v3: 共享 map 集中初始化, 运行时 bundle 复用;
  修掉运行时重启处理、WAN 作用域、IPv6 前缀匹配、IPv4 定时器清理和 ICMP 处理上的问题.
- 修正网关关闭时的取消处理.
- 内部整理: 线程和异步任务命名; 优化 Geo 缓存的内存读取.
  :::

## v0.16.3 (2026-03-11)

判决查询支持多目标 IP; Geo IP 支持 TXT 导入; 若干展示细节修正.

::: details 详细变化

- 判决查询支持一次查多个目标 IP, 并做了输入校验.
- Geo IP 服务会对 IP mark 的网段去重.
- 判决结果的缓存一致性会正确判断并展示, 尤其是 `keep_going` 动作.
- DHCP 分配表里, 未知设备的名称可以由 MAC 反查显示.
- 支持导入 TXT 格式的 Geo IP, key 可配置.
  :::

::: details 详细变化

- 证书账户的邮箱做打码.
- 指标清理和聚合解耦, 新增若干配置参数, DuckDB 的线程管理也做了调整.
  :::

## v0.16.1 (2026-03-05)

证书管理成型(ACME 账户、DNS 挑战、按 SNI 动态解析), 新增 DoH 与 netlink 模块.

::: warning 需要注意的变更
界面语言固定为 `zh`, 不再按浏览器语言自动探测.
:::

::: details 详细变化

- 新增 `netlink` 模块, 把接口解析、链路管理、地址处理和事件监听集中起来.
- 证书管理成型: ACME 账户的注册、验证和停用, 带 DNS 挑战的证书申请,
  账户与订单管理, 证书详情和下载, 申请取消与状态同步.
- 有效证书不再允许更换 ACME 账户, 并为此补了专门的错误提示.
- 接口的 TLS 证书支持按 SNI 动态解析.
- 支持 DNS over HTTPS(DoH).
- 支持 HTTPS 类型的 DNS 记录, 并能按 IP 版本过滤 IP hints.
- DHCP 和 PPPoE 客户端新增指数退避重试.
- 修正 PTY 会话创建失败的问题, shell 会依次尝试多个候选;
  终端数据改用 `TextDecoder` 解码, 字体偏好也更新了.
- ICMPv6 选项的解析和序列化用 `deku` 重写.
- 复用 pinned map 时会检查类型、条目数和 flags, 避免混用.
- 界面语言固定为中文, 不再探测浏览器语言.
- IPv6 分流的匹配长度更新; DHCPv6 和 ICMPv6 里优先使用 link-local DNS.
  :::

## v0.15.0 (2026-03-01)

DHCPv6 服务器落地; RA 并入 LAN IPv6 并支持三种模式; PD 路由管理实现.

::: warning 需要注意的变更
原有的 ICMPv6 RA 界面组件与服务被移除, RA 的配置入口改为 LAN IPv6 服务器,
三种模式在同一个位置选择.
:::

::: details 详细变化

- 实现 DHCPv6 服务器.
- RA 配置和 PD 管理合并进 `ipv6/prefix` 模块, 引入 `IPv6PrefixRuntime`.
- RA 服务改成 LAN IPv6 服务器, 支持 Slaac、Stateful、SlaacDhcpv6 三种模式.
- DHCPv6 和 RA 的 IPv6 来源配置统一, DHCPv6 的前缀委派设置也简化了.
- 实现 IPv6 PD 的路由管理.
- 移除 ICMPv6 RA 相关的界面组件和服务.
- 新增 `LanOrUndefined` 区域要求, WiFi AP 模式限制在非 WAN 区域.
- pinned eBPF map 会检查键值大小, 避免复用时空布局不一致却悄无声息.
- 静态映射到本机时, egress 查找新增 `from_addr = 0` 的回退.
- NAT 测试按 IPv4/IPv6 拆成子模块, 覆盖静态和动态场景.
- 界面接入 i18n, 各组件陆续改用翻译文本.
  :::
